# 超インド式計算

10×10〜99×99の二桁同士の掛け算を、完全ランダムまたはショートカット別に練習する静的Webアプリです。

## このアプリでいう「超インド式」

河野玄斗さんが「超インド式計算法」として紹介している、二桁同士を3段階で処理する方法を中核にしています。

`x = 10a + b`、`y = 10c + d` とすると、

`xy = 100ac + 10(ad + bc) + bd`

です。アプリでは暗算しやすいように、次の順番で各桁と繰り上がりを確定します。

1. 右縦：`b × d`
2. クロス：`a × d + b × c + 繰り上がり`
3. 左縦：`a × c + 繰り上がり`

この万能法とは別に、条件が合う問題をさらに短く解くためのショートカット練習も収録しています。

- [『小学生でも99×99まで暗算できるドリル』書誌・目次](https://www.hanmoto.com/bd/isbn/9784815623135)
- [河野玄斗さんへのインタビュー](https://kosodate.mynavi.jp/articles/35882?page=2)

## 主な機能

- 10〜99の全組み合わせを一巡するシャッフル出題
- 8,100通り（順序あり）／4,095通り（交換法則による重複除外）の切替
- 回答後の正誤判定・タイマー・連続正解数
- 数字を入れずに回答できる「わからない」ボタン
- 問題ごとの段階的な解説
- 回答後に正誤を問わず解説を自動表示
- 十の位・一の位、縦線・クロス、繰り上がり、答えの各桁を図で追えるビジュアル解説
- 万能法と7つのショートカットを、条件・理由・例題で学べる勉強モード
- 各レッスン末尾に、その型だけからランダム出題する3問チャレンジ
- 完全ランダム時は、その問題に適用できる最短のショートカットを自動選択
- 万能クロス法、十の位同じ・一の位の和10、一の位同じ・十の位の和10、100付近、平方差、末尾5の平方、11倍、基準数法
- 間違えた問題を端末内に保存し、苦手問題モードで復習
- PWA対応・オフライン利用

## 起動方法

`index.html`を直接開いても基本機能は動きます。PWA・オフライン機能まで確認する場合は、このフォルダで簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## ファイル構成

- `index.html` — 画面構造
- `styles.css` — UIデザイン
- `app.js` — 出題、採点、解説、記録ロジック
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフラインキャッシュ

## 検証済みの範囲

- 10〜99の順序あり全8,100組で万能クロス法の結果が通常の掛け算と一致
- 順序あり8,100問／重複除外4,095問の切替
- SafariとChromium系ブラウザで回答、採点、解説、苦手問題保存を確認
